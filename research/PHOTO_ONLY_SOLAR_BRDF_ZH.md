# 照片恢复太阳是否改善 BRDF：当前实验目标

更新：2026-09-19。此文件覆盖此前以阴影 IoU 为主要成果的实验方向。

## 要回答的问题

在高真实感室内多视角照片中，显式估计太阳方向、强度和天空照明，
能否减少把光照误认为材质的错误，并提高 BRDF 恢复精度？
这是待检验假设，不是目前已有结论。之前 EXP0012 的灰色扫描网格、
已知反射率和直射光分量监督，只证明了有限条件下的太阳几何恢复。

## 数据生成与估计严格分开

- 生成端保存完整几何、纹理、BRDF、窗户透射模型、太阳方向/强度/角直径、
  天空、室内灯光、相机、曝光/响应、随机种子、渲染器版本及线性 HDR。
- 主实验估计端只接收照片及图像分组，不读取这些真值。
  所需相机和几何从同一套照片重建；不能偷用扫描真值。
  时间、GPS、朝向和太阳轨迹只在单独的辅助信息实验中开放。
- 为先排查材质—光照机制，另设相同已知几何/相机的受控实验。
  所有方法获得相同输入，但它不能被称为严格的照片输入实验。
- 生成目录不传入估计器；导出输入目录使用白名单复制。
  评分器在估计结果冻结后读取真值，记录输入清单与哈希。
  分目录本身不构成访问隔离，实际运行还需限制估计进程可见路径。

## 场景与真实感

主线保留 ScanNet++ 真实空间几何，补充明确的 PBR 材质与窗户透射。
这些材质参数是重新赋予的受控真值，不是原房间的实测 BRDF。
原照片包含阴影和高光，不能直接当作纯反照率贴图。
修补几何、修改窗户、贴材质均须保存修改前后版本与来源。

人工建模 PBR 室内作为工程调试和额外受控基准，必须与真实扫描场景分开报告。
现已取得 Contemporary Bathroom（Mareck，CC0）和 Country Kitchen
（Jay-Artist，CC BY 3.0），来自 https://noobody.org/resources/ 。
它们的完整模型/纹理已下载，但尚未验证为合格的太阳重渲染数据。
源 XML 使用面光源；不得仅记录一个太阳角度就宣称具有太阳真值。

质量验收先于扩量：原始线性输出必须有限；保留未降噪图；独立随机种子检验
采样收敛；检查漏光、扫描洞、窗户遮挡、纹理、镜面和间接照明。
固定照片生成响应，不能逐图自动曝光抹掉实际光照变化。
给出渲染图和真实照片的视觉对照，但不同光照的原照片不充当逐像素真值。

## 对照实验

1. 原始 IRIS：保留其原有机制。
2. IRIS + 通用外部照明：避免把“补上环境光”误归因于太阳几何约束。
3. 我们的方法：未知太阳方向/强度和 BRDF 联合估计。
4. 太阳真值辅助对照：只为诊断剩余误差，不计入照片输入方法。

共享图像、重建几何、材质表达、优化预算和种子。另比较“有太阳表示但没有
太阳几何约束”，区分表示能力和约束的效果。不把 +10° 错误太阳当作 IRIS。

先固定一次光照做多视角反演；再比较多时刻联合反演。
场景内划分未见视角与未见光照，场景间独立划分开发集和测试集。
多张照片不等于多个独立房间，统计以房间为单位。

## 主指标与可识别性

主要评分反照率、粗糙度，以及适用材料上的金属度；报告空间误差图、
受光/阴影区域分组误差和未见光照下的重渲染误差。
太阳角误差和训练照片 PSNR 是辅助指标。

不同 BRDF 模型的参数不一定等价：例如 GGX alpha 与 IRIS roughness
不能直接相减；IRIS 使用 alpha = roughness²。原始塑料、导体、玻璃
也不能未经转换就套用金属度真值。采用匹配 BRDF 的受控子集做参数评分，
保留原材质的复杂子集做 BRDF 角度响应及重照明评分。玻璃单独评价。

仅凭未标定照片一般不能确定光强与反照率的绝对尺度。照片输入主结果
报告明确的尺度对齐反照率误差，同时报告未对齐误差；对齐仅用于评分，
不能将真值光强或真值均值反馈给训练。绝对精度另设具有真实标定输入的实验。

结论成立需要在多个独立房间上改善 BRDF，并保持未见光照预测的改善。
若只提高图像拟合或太阳角度准确率，则不能声称得到更准确的材质。

## 当前完成与未完成

已完成：真实扫描几何的灰模生成流程；原始 IRIS 官方 checkpoint 渲染；
本实验协议；两套完整 PBR 资产下载和 ZIP CRC 检查。

未完成：通过质量验收的高真实感太阳数据集、严格照片输入的联合反演、
BRDF 对照结果。不能将之前的阴影 IoU 当成这些工作的完成证明。
