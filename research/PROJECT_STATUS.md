## 一句话结论（目前）

- **显式太阳 ≫ 通用光照**：在受控房间里，显式太阳恢复的材质远好于任何通用光照表达（H1 在合成数据上成立）。
- **星历"标定"并没有让材质更好**：同样显式建模太阳时，标定版本（C）与从图像估计方向的版本（B）材质相当（R1 不成立）。
- **标定真正的用处是预测未见时刻**：
  - 合成数据上，外推到未见时刻时 C 远胜 B。
  - 真实数据上，主数据日 C 大胜，但重复数据日没有复现（R2-real 不成立）。
- **最大的弱点是脆弱**：
  - 太阳方向误差超过约 0.5°，材质恢复就明显变差。
  - 窗洞几何差 3 cm，所有显式太阳方法都崩溃，此时通用高分辨率环境贴图反而最好（EXP0036，目前只有 1 个种子）。

## 最强证据

| 真实数据：时间 + GPS 算太阳高度角 | 误差约 0.5° | EXP0028 |

## 最弱的假设

"太阳方向和窗洞几何能被足够精确地知道"，这一点不成立：
- 太阳方向误差 0.39° 时，材质相关系数从 0.93 降到 0.80；1.6° 时降到 0.36（EXP0035）。
- 窗洞几何 ±3 cm 时，显式太阳方法的相关系数降到约 0.35（EXP0036）。
- 真实重建的窗户几何误差通常就在厘米级。

## 预先登记规则的判定

T11 合成 v1（`SOLARIR_HYPOTHESIS_TEST_ZH.md`；D0019/D0020 为协议修正）：

- **R1 不成立**：C 的地板 MAE 只比 B 低 6%（要求 ≥15%）；相关系数上 B（0.887）反而略高于 C（0.872）。
- **R2 成立**：14:30 上 C 比 B 高 +12.7 dB，IoU 高 +0.61。
- **R3 成立**：C 多时刻 MAE 0.034，远低于单时刻的 0.13。
- 按结论矩阵，贡献收缩为"可预测未见时刻"；材质上没有超过显式太阳的已有做法。

v2（EXP0036，窗洞 ±3 cm + 沙发遮挡）：
- 1 个种子：C 的 MAE 比 B 更差（0.111 vs 0.095）。
- R1 按 v1 + v2 合并判断：**不成立**。

EXP0037（真实数据）：
- 主数据日 C ≫ B，重复数据日 C < B（0.18 vs 0.20）→ **R2-real 不成立**。
- 原因：重复数据日训练时刻的光斑太小（约 0.3%），导致朝向标定不稳定。

## 新机制发现（D0020）

显式太阳之后，剩余的材质–光照歧义来自**天空/环境光项**，不是太阳：
- 16×32 自由天空会和反照率互相补偿。
- 天空固定为真值时，相关系数 0.96。
- 4×8 天空为 0.92。
- 协议中天空分辨率的选择参考了 oracle 信息，已声明。

## 新颖性（`NOVELTY_AUDIT.md`、`LITERATURE_REVIEW.md`）

- Krawez et al. RA-L 2021 已做过：室内 + 星历太阳（地理位置 + 时间 + 给定朝向）+ 经窗户传输 + 预测一天中各时刻的外观。只是正向预测，材质来自单独的采集。
- 卫星 NeRF（S-NeRF / Sat-NeRF / EO-NeRF）已用已知太阳方向和多日期影像分离阴影与反照率。
- **创新性信心：低。**
  - 唯一剩下的空白是"标定太阳的运动作为室内多视角材质恢复的监督"。
  - 而本页的结果显示，这种标定在材质上并不比图像估计的太阳更好。

## 发表可行性

- 结论：**kill 作为主会论文的"材质"主张。** 最多是 workshop 或专门会议量级的"可预测未见时刻 + 脆弱性分析"。
- 不夸大：真实跨时刻的材质验证（多视角）根本没有数据，完全未检验。

## 接下来 3 个实验

1. **EXP0036 补完 3 个种子**，并加一组"窗洞几何也作为参数优化"的对照：检验脆弱性是否能被修复；如果能修复，C 与 B 的差距会不会重新出现。
2. **B 的强基线**：用"已知地球自转、未知地点"的物理约束轨迹做外推。检验 R2 的优势是不是只来自 B 的线性外推太弱（审稿人一定会问）。
3. **真实数据的标定协议**：预先登记"最小光斑面积 / 跨日共享朝向"后，在 coda_334 的第三天（2023-06-22）和两天互换上重跑 EXP0037。
