# EXP0012：真实 ScanNet++ 空间的可控重渲染

已经在 `1b379f1114` 的原始扫描网格上完成第一轮实验。房间、沙发、桌子、窗框和遮挡来自真实扫描；材质和太阳／天空照明由实验指定。

可视化：`experiments/out/EXP0012_scannetpp_rerender/run_01/index.html`。
静态对比：同目录 `comparison.png`、`comparison.pdf`；动画 `sun_changes.gif`。

## 实际执行

- 原始网格 4,218,877 个三角面，未修洞、未简化、未替换为方盒子。
- 4 个真实机位 × 4 种太阳条件 × 2 个渲染种子，共 32 组数据。
- 每组提供完整路径追踪 RGB、直接太阳光图、地面阳光区域；每个机位保存位置、法线、深度、有效像素和地面掩码。
- 分辨率 384×256、64 SPP、最大路径深度 8。64 张 EXR 均通过有限数值检查。
- 全场景指定双面漫反射材质，反射率 0.55；未把照片或扫描颜色当作无光照的材质真值。
- 原始相机位姿转换到网格坐标；渲染器与计算代码的逐像素射线误差低于 2×10⁻⁷。
- 透视相机使用原始 fx，并令 fy=fx；原始 fx/fy 的约 0.28% 差异记录在 manifest。这是明确的相机近似。
- 太阳角度是场景坐标中的仿真设定，没有伪造真实日期、朝向或拍摄时间。

## 冻结的拟合和评估

仅使用训练光照、机位 0、种子 101 的直接光图，拟合太阳方向。训练真值为方位 223.7°、高度 23.4°，不在 1° 搜索网格上。测试时提供真实的相对太阳角度变化，不读取测试图拟合参数。

阳光区域标签来自单独的直接光渲染，以已知全照明强度的一半为阈值；不是把几何预测输出直接当标签。两者仍共享 Mitsuba 和相同网格，不能称为独立渲染器验证。

| 测量 | 结果 |
|---|---:|
| 恢复方向 | 方位 224°，高度 23° |
| 方向误差 | 0.486° |
| 未见光照 A 的平均阳光区域 IoU | 0.865 |
| 未见光照 B 的平均阳光区域 IoU | 0.935 |
| 两种未见光照平均 IoU | 0.900 |
| 使用真实太阳方向的几何参照 IoU | 0.980 |
| 故意把真实太阳方位偏移 10° 的控制项 | 0.339 |

这是方向／可见性模块的受控结果。直接光图、已知材质和精确仿真网格都是有利条件；没有完成未知材质恢复，也没有在此数据上比较完整原始 IRIS 与新方法。

## 现实误差检查

保持模型不变，给相机加入场景竖轴旋转误差，并重新与真实网格求交：

| 相机误差 | 两个方向平均 IoU |
|---|---:|
| 0° | 0.900 |
| ±0.25° | 0.886 |
| ±1° | 0.822 |
| ±3° | 0.699 |

标定误差确实会影响光斑预测。另一个“接收点三维抖动”压力测试在 1 cm / 5 cm 下得到 0.502 / 0.418，但这会把点移入网格内部、制造自遮挡，因此只能作为数值敏感性记录，**不能解释为真实网格噪声性能**。上述相机误差实验使用重新求交，避免了这一问题。

测试方向中，平均 98.8% 的未遮挡地面射线穿过先前近似标注的窗户范围。这是漏光诊断，不是独立的窗户真值认证。原网格的缺口仍保留，图中也能看到；无效表面不计入地面指标。

## 复现与证据

整理后的单条命令已完整复跑：

```bash
MPLCONFIGDIR=/tmp/iris-mpl \
LD_LIBRARY_PATH="$PWD/.toolchain/compiler/lib" \
.venv/bin/python experiments/scannetpp_rerender.py \
  --out experiments/out/EXP0012_scannetpp_rerender/new_run
```

```bash
.venv/bin/python experiments/visualize_scannetpp_rerender.py \
  experiments/out/EXP0012_scannetpp_rerender/new_run
```

两次执行的所有方向、IoU 和逐图 TP/FP/FN 计数一致。浮点图不是逐字节一致：完整 RGB 的重复运行 RMSE 为 0.000218，直接光图 RMSE 为 1.25×10⁻⁹；保留了差异，未宣称图像完全确定性。

证据在 `research/evidence/EXP0012/`，包含配置、数据与源码哈希、相机信息、逐图指标、相机误差实验和复跑核对。渲染与评估仅使用一个房间；机位和随机种子不算独立房间样本。

当前完成的是 **真实扫描空间 → 可控仿真数据 → 留出光照模块验证**。接下来的科研比较应在相同输入条件下接入原始 IRIS 和新光照模型，再评估未知材质、更多房间以及真实跨时间照片。
